# Papers

本目录保存项目 canonical paper notes。Zotero `FSA` collection是user-curated
seed/reference library；外部检索发现的重要论文与专题审计也必须在本目录落地。

默认语言：中文。

每篇 note 至少包含：

- bibliographic source
- PDF/full-text completeness
- mechanism claim
- tensor semantics
- critical defaults
- known failure modes
- relevance to one model for multi-horizon
- relevance to future-aware architecture
- relevance to MoE-style conditional computation
- adopted details
- rejected details

外部调研note还应记录search date、query/topic scope、primary source与official code状态、是否已在Zotero
seed中出现，以及coverage/freshness不确定性。Zotero未收录不能作为文献空白或novelty证据。
