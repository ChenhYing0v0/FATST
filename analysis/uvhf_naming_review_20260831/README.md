# UVHF naming review

This directory contains review-only plotting sources and outputs for the
UVHF/MSD/BCA terminology revision. The frozen scientific data and plotting
geometry are inherited from the paper-facing figures; only model and component
labels are revised.

The original HoriScope submission assets remain unchanged.

## Approval status

The author approved the complete naming revision on 2026-09-01. The clean,
uncoloured package in `UVHF_KBS_submission/` is now the canonical KBS
submission source. This directory and `UVHF_KBS_submission_highlighted_review/`
remain the audit and comparison materials for that promotion.
