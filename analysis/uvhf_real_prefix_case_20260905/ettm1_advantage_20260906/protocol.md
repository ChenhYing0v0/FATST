# ETTm1 精度与前缀分歧优先的案例选择

2026-09-06；仅用已有 validation 预测，不训练、不选 checkpoint、不访问新 test。
根据用户反馈重设展示目标：各独立区间的 UVHF 精度优势与 TimeMixer 公共前缀分歧优先；不再优先选择差距居中的案例。
这是已看过数据后的定向选样，不能声称预注册、随机或代表总体。

沿用强 UVHF 全程/尾程拟合条件。10 个有效分段与 horizon 组合的最小 MSE 改善至少30%，MAE至少15%；前96平均四模型极差/真实值范围至少0.12，超过真实范围10%的前缀步数比例至少50%；UVHF 最后192步 R2超过TimeMixer。
TimeMixer 每个完整 horizon R2至少0.2，H720至少0.4。相较前版放宽每个horizon至少0.5及60%增益上限，防止把明显优势排除；保留baseline本身具备预测能力的门槛。
按最小分段MSE增益乘前缀可见性降序；同变量相距至少96步，审阅前三例。相邻窗口不作为独立重复证据。

图形合同：复用 Python 单主图+完整1–96 inset，原始尺度720个预测点全部保留，不平滑、不移动时间、不剪除失败区间。SVG/PDF可编辑，PNG/TIFF预览；记录真实数据CSV、分段指标与QA。此图支持单案例的精度和前缀分歧，不支持总体效应或因果归因。TimeMixer仍为visualization专用checkpoint，非Main-I来源。
